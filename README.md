# شامخ — نموذج تجريبي صوتي

هذا مشروع Flutter مصدر قابل للتجربة، **ليس ملف APK جاهزًا**.

## التشغيل
1. ثبّت Flutter وAndroid Studio (أو استخدم Flutter موجودًا لديك).
2. نفّذ `flutter create shamikh_mvp` في مجلد جديد ثم انسخ `pubspec.yaml` ومجلد `lib` من هذه الحزمة إلى المشروع الناتج.
3. Android: أضف `<uses-permission android:name="android.permission.RECORD_AUDIO" />` داخل `android/app/src/main/AndroidManifest.xml` قبل `<application>`.
4. iOS: أضف `NSMicrophoneUsageDescription` و`NSSpeechRecognitionUsageDescription` مع وصف عربي لاستخدام الميكروفون والتعرف على الكلام إلى `ios/Runner/Info.plist`.
5. نفّذ `flutter pub get` ثم `flutter run` على جهاز حقيقي مع دعم التعرف على الكلام باللغة العربية.

## حدود النسخة
- تتعرف على الكلام باستخدام خدمة التعرف المتاحة في الجهاز؛ قد تحتاج الإنترنت بحسب نظام الجهاز.
- محلل الأوامر **محدود**: اليوم، بكرة، بعد بكرة، وأيام الأسبوع، والساعة بصيغة رقمية مع صباح/عصر/مساء. لا يفهم كل الصيغ الطبيعية، ولا يحسب مواقيت الصلاة، ولا يدعم كل التكرارات.
- يحفظ المهام محليًا على الجهاز باستخدام SharedPreferences، دون حسابات أو مزامنة.
- لا تُرسل إشعارات فعلية؛ حقل التذكير يُحفظ فقط. لا تستخدمه للتذكيرات الطبية أو الحرجة.
- لم يتم تشغيل Flutter أو اختبار البناء في هذه البيئة؛ يلزم اختبار على جهازك.
